# Practice SoftwareTesting API Automation Suite

This is an independent, self-contained API testing microservice framework built to validate the endpoints provided by the ExpandTesting practice platform.  The purpose of this testing suite is to ensure the functional health, schema reliability, and security contracts of the production REST APIs hosted on the **[TOOL SHOP](https://v4.practicesoftwaretesting.com/#/)**, **[GitHub URL](https://github.com/testsmith-io/practice-software-testing)**, **[Toolshop REST API technical description](https://api-v4.practicesoftwaretesting.com/api/documentation)**.

For simplicity and clearity, only the endpoints of *User* and *Invoice* are implemented and the "Has a" design patern is utilized between Invoice and User.
